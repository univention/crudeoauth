# Security Policy

crudeoauth is maintained by [Univention GmbH](https://www.univention.com/).

## Reporting a vulnerability

We encourage reporting security issues via encrypted email.
We offer the [security.txt](https://www.univention.de/.well-known/security.txt)

We appreciate responsible disclosure for vulnerabilities that affect our products.

Please read the [Univention Security Policy](https://www.univention.com/security-policy/).

## Overview about security fixes

All security fixes are announced as [Github Security Advisories](https://github.com/univention/crudeoauth/security/advisories)
and in our [errata updates overview](https://errata.software-univention.de/#/?package=crudeoauth&type=security).
